# Lessons

- **2026-10-17 — usage data is native now.** Claude Code (≥ ~2.1.x) pipes `rate_limits.{five_hour,seven_day}.{used_percentage,resets_at}` (resets_at = epoch *seconds*) to the statusline, plus `refreshInterval` in `statusLine` settings. Dropped `fetch-usage.sh`, its hooks, and the OAuth token scraping. Gotcha: the repo's `fetch-usage.sh` had quietly reverted to the macOS-keychain version (`security`) through a merge, while `~/.claude` held a Linux version — the repo copy never worked on WSL. Check the installed copy against the repo, not just the repo. The payload doesn't include the auto-compact threshold, so the warning uses a configurable heuristic.
- **2026-10-17 — jq `//` swallows `false`.** `.prompt_cache.warm // ""` turns `false` into `""`, which hid the "cache cold" state; the tests caught it. Use `if . == null then "" else tostring end` for booleans. Single-pass parsing uses `jq -r '@sh "var=\(...)"'` + `eval` — `@sh` quoting makes that safe against payload strings (covered by a `$(touch …)` injection test). The statusline payload also carries `prompt_cache.{warm,expires_at,ttl,hit_ratio}`, and Claude Code re-renders at cache expiry on its own.
- **2026-10-25 — Ideogram has no balance source.** `GET /v2/account/usage` (sources api and app) returns buckets with empty `line_items` for a month with ~2000 credits spent, so line 3 counts from a shared, app-neutral ledger (`~/.local/share/ideogram/ledger.jsonl`) plus `~/.config/ideogram/plan.json` (2400/month, resets on the 1st, optional "credits left as of" anchor), taking the max of that and the usage API. Its line-item shape is a guess until it returns data. Don't read usage out of one app: a first draft did `docker exec posterize-app-1 …`, which breaks when that app goes away.
- **2026-10-25 — ElevenLabs quota needs `user_read`.** `/v1/user/subscription` answers 401 `missing_permissions` for a TTS-only key. Never block a render on the network: the statusline reads a cache and spawns `usage-fetch.sh` detached when it's stale (mkdir lock, stale after 60s). Keys go to curl on stdin (`-H @-`), never argv.
